**Tagline:** Provision SSL reseller services from PeltyCMS orders

## SSL reseller provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on SSL reseller when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable SSL reseller API/panel
- API token or login configured in Pelty
